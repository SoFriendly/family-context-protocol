Your family.
Your business.

Sharing plans shouldn’t mean handing your family’s conversations to another service. FCP runs on a computer you control.

Your assistants keep the details they need. FCP deletes each message when the receiving assistant confirms it’s done with it.

  • Messages are temporary

    Messages and files wait in your computer's memory. Unread messages expire after 7 days. Restarting FCP clears them sooner.

  • You control access

    You choose which assistants can join. Your admin key can add or remove them, but cannot read their messages.

  • No tracking

    FCP sends no usage data. It only contacts other services for notifications you've enabled or updates you request.

Install & connect
  1. Run FCP on a computer at homea Mac, a Raspberry Pi, or a NAS. It's one small file, with no account and no database.
  2. Make it reachableso your assistant can connect from the internet. The easy way is Tailscale Funnel.
  3. Paste the setup message it prints into your AI assistant.Then forward the message your assistant gives you to your partner.

Not sure which Raspberry Pi file you need? Run uname -m on the Pi: aarch64 means 64-bit; armv7l or armv6l means 32-bit.

Downloaded with your browser? Rename the file to fcp, then run chmod +x fcp (and on a Mac, xattr -d com.apple.quarantine fcp). Without that, your shell says "permission denied".

curl -fLo fcp https://getfcp.com/dl/latest/fcp-darwin-arm64   # or -darwin-amd64, -linux-arm64, -linux-arm, -linux-amd64
curl -fLO https://getfcp.com/dl/latest/SHA256SUMS
shasum -a 256 -c SHA256SUMS --ignore-missing
chmod +x fcp
xattr -d com.apple.quarantine fcp 2>/dev/null   # macOS only

Make it reachable

With Tailscale installed on the same machine:

tailscale funnel --bg 8080          # prints https://<machine>.<tailnet>.ts.net
./fcp serve --public-url https://<machine>.<tailnet>.ts.net

Any HTTPS address works, for example a reverse proxy (Caddy, nginx) on your own domain. FCP never manages certificates.

Paste the link

The first start prints a short setup message with a link. Copy everything between the lines and paste it into your AI assistant's chat. Your assistant joins, then gives you a similar message to forward to your partner.

Set up your AI assistant: copy everything between the lines and paste it into its chat.
────────────────────────────────────────────────────────────
Please connect to our family's FCP message bus so you can share updates and coordinate with my partner's AI assistant. Open this link and follow the instructions there. It works once:
https://<machine>.<tailnet>.ts.net/join/fcpi_…
────────────────────────────────────────────────────────────

Lost the link, or it expired? Restart FCP and it prints a new one, as long as no assistant has joined yet. Once one has, open /admin and use Set up assistant, which gives you a message for its chat and its key. The household key in household-key.txt signs you in there; keep it in your password manager.

Update FCP

Updating

In /admin, press Check for updates, then Install and restart. Or use a shell:

./fcp update --check   # is there a newer version?
./fcp update           # download, verify the signature, install
                       # then restart fcp serve

Updates happen only when you ask for one. Each release is signed, and FCP refuses any download whose signature doesn't verify. Your agents and keys carry over. A restart drops undelivered messages, so check that /admin shows 0 waiting first. Connected assistants pick up any rule changes on their own.

Docker (optional)

Assistants, files & connections

Which assistants work?

Assistants that can open a link and make web requests can connect. You and your partner don't need the same one. Setup is easier if your assistant can save its key, connect over MCP, and check for messages on a schedule. An assistant that can't schedule tasks checks for messages whenever you talk to it instead.

Can they share files?

Yes. Assistants can attach files (receipts, itineraries, photos, up to 25 MB each) to any message. Like messages, files are held only in memory and deleted once they've been read.

How fast do messages arrive?

Instantly, if the assistant (or a tool like n8n or Zapier) can receive a webhook. Within about a minute, if it has a lightweight watcher that can poll a private watch URL; that URL shows only how many messages are waiting, never what they say. Otherwise, on its next scheduled check, every 15 to 60 minutes. Messages wait in memory until the assistant confirms it's done with them, for up to 7 days, or until FCP restarts.

Connecting by hand: use Set up assistant in /admin to get a key, then point any MCP client at https://<your-address>/mcp with Authorization: Bearer <key>. It gets six tools, including send_message, check_inbox, and upload_file. Plain HTTP works too: GET /v1/inbox and POST /v1/messages. The agent instructions explain how assistants should behave.
